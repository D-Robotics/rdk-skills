# D Robotics OE S 文档检索规则

本文定义 OE S 工具链官方资料的检索方式。官方技术事实必须来自本次任务中检索到的 RDK 文档 MCP 页面；本地 Skill、references、代码快照、示例和记忆只可辅助路由与项目流程，不能作为官方依据。

## 适用问题

涉及 PTQ、QAT、量化、校准、编译、HBIR/HBM、部署、板端推理、评测、工具命令、参数、API、配置项、芯片平台映射或版本兼容性时，必须检索官方文档。

## 检索步骤

1. 使用 `mcp__rdk_docs__search_docs`，指定 `manual=oe-s`、`source=docs`，按用户任务检索官方手册。
2. 使用 `mcp__rdk_docs__get_page` 打开搜索返回的相关官方页面，核对适用平台、版本、前置条件和操作阶段。
3. 复杂问题按不同术语或阶段继续检索，直到官方页面足以支持回答；准确引用页面标题和链接。
4. 用户需求映射到哪个 Skill，由 `.drobotics-s/skill-index.json` 决定；Skill 与本地 references 只提供路由及项目工作流程。

不要用本地 `docs/index.md`、OE 包代码快照或 Skill 中的静态说明代替官方手册检索。检索结果与本地流程资料不一致时，以本次检索到的官方页面为技术依据，并说明需要调整的本地流程。

## 检索阻塞

如果文档 MCP 工具不可用、没有相关结果或页面没有说明所需细节，明确报告阻塞和缺少的证据。不要从旧版本资料、示例代码或通用知识推测 CLI、参数、API、配置或版本行为，也不要把未经确认的命令交给用户执行。可以继续与缺失官方资料无关的工作，并明确标出未完成部分。

## 查询词提示

查询可以使用用户描述、工具名或流程阶段，例如：PTQ/QAT、HMCT、`hb_compile`、`hb_config_generator`、HBDK、UCP、板端推理、精度、性能、`march` 和版本号。查询词只是帮助检索，不代表已确认该工具、参数或流程受当前版本支持。

# X5 工作区

## 1. 工作区概览

本 Pack 是 D-Robotics X5 OpenExplorer 的 Agent Skill Pack V2，仅覆盖 X5 芯片。

- 工作区根目录：`.drobotics/`
- 版本文件：`.drobotics/VERSION`
- Skill 索引：`.drobotics/skill-index.json`
- 文档目录：`.drobotics/docs/`
- Skill 目录：`.drobotics/skills/`
- 平台资产：`.drobotics/platforms/x5/`
- 当前版本：`2.0.0`

## 2. 使用规则

- 遇到 X5 OpenExplorer 请求时，先使用 `.drobotics/skills/x5-router/SKILL.md` 作为顶层路由 Skill。
- x5-router 会按输入、产物、环境和风险选择一个主 Skill，并生成 `route.json`。
- 未经检索，不要猜测 X5 工具链命令、参数或流程细节。
- Pack 内置说明位于 `.drobotics/docs/`；补充官方资料必须从本地文档包检索。
- S/X5 的 `hbm_runtime` 专用 Markdown 也通过检索器加入结果，不能再调用云端 MCP。

## 3. 执行前检查

- 开始 X5 工具链任务前，先检查用户是否提供了可用板卡信息。
- X5 板卡按 X5 处理，使用 `bayes-e` march、`.bin` 产物格式。
- 优先从环境变量中查找板卡信息，例如 `X5_BOARD_IP`、`BOARD_TYPE`、`BOARD`。
- 如果环境变量没有提供，再检查项目内相关配置文件。
- 如果任务涉及板端运行但没有找到板卡信息，必须先向用户确认。
- X5 必须验证板端 `/etc/version >= 3.5.0`。

## 4. 强制边界

- **PTQ**：`hb_mapper`、`bayes-e`、`.bin`。
- **Plugin QAT**：`March.BAYES_E`、`check_model`、`compile_model`/`export_hbir`、`.hbm/.hbir`。
- **排除**：HAT、HAT config、Trainer、Model Zoo、`tools/compile_perf.py`。
- **隔离**：X3、S 系列模型、Runtime、wheel/DEB 和命令不得复用。
- `March.BAYES` 属于 J5，不得复制到 X5。

## 5. 本地文档检索规则

只要模型参数、函数、API、配置项、命令参数、流程顺序、默认行为或错误码存在不确定性，必须运行本地文档检索：

```bash
python .drobotics/scripts/search_local_docs.py --query "<检索关键词>"
```

- 文档根通过 `OE_DROBOTICS_DOC_ROOT` 环境变量或工作区相对发现。
- 本地 Skill 与本地文档存在差异时，说明差异并采用保守方案。
- 需要获取固定版本的 SDK、文档或 Docker 离线包时，先阅读 `.drobotics/docs/offline-artifact-delivery.md`。
